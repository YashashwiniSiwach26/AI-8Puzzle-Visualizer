Introduction to the 8-Puzzle Problem

The 8-Puzzle is a sliding-tile puzzle on a 3×3 board holding the tiles 1–8 and one empty square (the blank). A move slides a tile that is next to the blank into it, which is the same as moving the blank up, down, left or right. The aim is to rearrange an initial state into a goal state using as few moves as possible.

As a state-space search problem:

  • State: an arrangement of the nine cells (9!/2 = 181,440 reachable from any solvable start).
  • Actions: move the blank Up / Down / Left / Right (2–4 legal moves).
  • Transition cost: 1 per move.
  • Goal test: the current state equals the goal state.

Exactly half of all arrangements are unreachable from a given goal; this app checks solvability with inversion parity before searching.

What you can do here
  • Enter your own initial and goal states, or generate a random solvable puzzle
  • Run Iterative Deepening Depth Limited Search (IDDLS), the assigned algorithm
  • Watch the frontier, explored list and successor states update step by step
  • Pause, step forwards/backwards, change speed
